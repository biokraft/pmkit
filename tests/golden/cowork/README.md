# pmkit skills for Claude Cowork

Upload each folder in `skills/` as a skill in Cowork.

- `pmk-feature-loop` — the front door: route an idea into the right stage
- `pmk-shape-idea` — turn a rough idea into a spec you have agreed to
- `pmk-build-safely` — build a spec one small reviewed task at a time
- `pmk-verify-visually` — drive a real browser before claiming it works
- `pmk-jira-flow` — keep the ticket's state matching reality

The safety gates in these skills are prose only on Cowork — nothing blocks a command for you there. If you want them machine-enforced, use Cursor or Claude Code.
